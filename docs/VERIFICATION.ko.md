# Rhythm Guard 1.0.0 검증 기록

## 빌드와 기능

- 배포 준비일: 2026-11-09.
- C++17 / MinGW-w64 GCC 15.1.0, 경고를 오류로 처리한 Windows x64 빌드 성공.
- 새 배포용 소스 복사본에서 다시 빌드한 EXE가 기존 기능 검사를 통과한 EXE와 SHA-256까지 일치.
- 입력 순서 검사 18개 재실행 통과.
- 동일 EXE의 Windows 훅 통합 검사 19개 통과 기록을 확인. 재배포 준비 중에는 전역 입력이나 창 조작을 반복하지 않음.
- Python 도구 2개 구문 검사 통과. 캐시를 생성하지 않는 방식으로 검사.
- 전역 단축키 등록 함수가 소스와 EXE의 가져오기 목록에 없음.
- 실행하면 차단 시작, 창·트레이로 전환, 종료하면 해제하는 동작을 유지.

## 업로드 전 개인정보 검사

- 명시한 소스·문서·아이콘 파일 14개만 새 저장소에 포함.
- 실행 파일은 저장소 이력 대신 릴리스 첨부로 제공.
- 문서, 소스, 파일명, EXE의 ASCII/UTF-16 문자열, 아이콘, 배포 ZIP 내부 파일 검사.
- 개인 이메일·전화번호·주민등록번호 형식, 개인 폴더와 절대 경로, 네트워크 공유 경로, 주요 토큰·비밀키·암호 패턴을 검사하고 원문도 검토.
- EXE에 디버그 디렉터리·디버그 섹션·COFF 심볼이 없음을 확인.
- Python 캐시, 빌드 중간 파일, 로그, 사용자 화면, 개인 설정, 진단 파일은 업로드에서 제외.
- 커밋 작성자는 GitHub 계정의 공개 핸들과 GitHub 제공 비공개 이메일 형식을 사용. 개인 이메일이나 로컬 PC 이름을 넣지 않음.
- 저장소 설명과 릴리스 본문에도 개인 경로나 진단 원문을 포함하지 않음.

패턴 검사와 수동 검토를 수행한 범위의 기록이며, 모든 종류의 개인정보를 자동으로 완전히 판별한다는 의미는 아닙니다.

## 남은 확인

- 실제 키보드로 리듬게임을 플레이한 검증.
- 게임별 보안 모듈, 관리자 권한 차이, 다른 PC, 장시간 사용.
- 최종 버전의 추가 화면 확인은 사용자 중단 이후 진행하지 않음.
- 코드 서명은 적용하지 않음.
