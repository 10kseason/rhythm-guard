# Rhythm Guard 1.0.0

리듬게임 중 실수로 Alt+Tab을 눌러 화면이 전환되는 것을 막는 Windows용 무설치 프로그램입니다.

## 사용법

1. `RhythmGuard.exe`를 실행합니다. **실행하면 바로 차단됩니다.**
2. 게임을 플레이합니다. 창은 최소화하거나 **트레이로 숨기기**를 눌러두면 됩니다.
3. 잠깐 전환하려면 창의 **차단 끄기**를 누릅니다. 다시 누르면 차단됩니다.
4. 사용이 끝나면 **종료** 또는 창의 **X**를 누릅니다. 차단도 함께 해제됩니다.

트레이 아이콘을 클릭하면 창이 다시 열립니다. 우클릭 메뉴에서도 차단 전환·즉시 해제·종료를 할 수 있습니다. 숨긴 상태에서 EXE를 다시 실행해도 기존 창이 열립니다.

**전역 단축키는 등록하지 않습니다.** 프로그램을 시작할 때마다 차단이 켜집니다.

## 차단 범위

- Alt+Tab, Alt+Shift+Tab, Ctrl+Alt+Tab을 차단합니다. 왼쪽/오른쪽 Alt를 지원합니다.
- 앱이 실행되어 있고 차단이 켜져 있는 동안 **모든 프로그램**에 적용됩니다. 게임 자동 감지 방식은 아닙니다.
- Tab 단독, Shift+Tab, Alt 단독과 나머지 키는 그대로 통과합니다.
- 게임에서 Alt+Tab 자체를 키 조합으로 사용한다면 해당 Tab 입력도 차단됩니다.

## 실행 환경과 동작

- Windows 10/11, 64비트용입니다. 별도 런타임 설치 없이 EXE 하나로 실행합니다.
- 일반 사용자 권한으로 실행합니다. 시작 프로그램이나 서비스를 등록하지 않습니다.
- 키 입력을 저장하거나 전송하지 않습니다. 네트워크·설정 파일·레지스트리를 사용하지 않습니다.
- 게임 프로세스에 코드를 주입하지 않고 Windows 저수준 키보드 훅으로 필요한 Tab 이벤트만 차단합니다.
- 차단이 꺼져 있으면 훅도 해제합니다. 종료하면 남아 있는 차단 프로세스가 없습니다.
- 오류가 나면 차단을 켜진 상태로 표시하지 않습니다. 창 아래의 Windows 오류 번호를 확인해주세요.

## 검증 범위

- 키 입력 순서 검사 18개 통과.
- 실제 Windows 훅에 테스트 입력을 보내는 통합 검사 19개 통과.
- 실행 즉시 차단, 양쪽 Alt, Alt+Shift+Tab, Ctrl+Alt+Tab, Tab/Shift+Tab 통과, Alt를 먼저 떼는 경우, 버튼 해제/복원, 트레이, 중복 실행, 종료 후 복원을 확인했습니다.
- 검사는 테스트용 Tab 입력을 별도 훅에서 받아 OS 화면 전환을 막는 방식으로 진행했습니다. 실제 키보드로 게임을 플레이한 검증과 게임별 보안 모듈 호환성은 아직 확인하지 않았습니다.
- 키보드 훅 콜백은 전용 스레드에서 짧게 처리합니다. Windows가 과도한 지연 등으로 훅을 제거하는 상황까지 차단 지속을 보장하지는 않습니다.
- 실행 파일은 코드 서명되지 않은 로컬 빌드입니다.

## 소스 빌드

별도 소스 ZIP에는 C++ 코드, 아이콘, 매니페스트, 빌드 스크립트와 검사가 포함됩니다. MSYS2 MinGW-w64의 `g++`, `windres`를 PATH에서 찾을 수 있어야 합니다.

```powershell
.\build.ps1
python -B .\tests\smoke_win32.py .\build\RhythmGuard.exe
```

첫 명령은 EXE를 만들고 18개 입력 순서 검사를 실행합니다. 두 번째 명령은 제한된 샌드박스가 아닌 일반 Windows 데스크톱에서 실행합니다. 테스트 시작 전 기존 Rhythm Guard를 닫고 Alt/Tab/Ctrl/Shift 키에서 손을 떼주세요. Python은 검사에만 필요하며 앱 실행에는 필요하지 않습니다. 아이콘을 새로 생성할 때만 Pillow가 필요합니다.

구현 참고: [Microsoft 저수준 키보드 훅 문서](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelkeyboardproc), [키보드 이벤트 구조체](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-kbdllhookstruct).
